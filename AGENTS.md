# DockRoll

DockRoll is a Go project for over-the-air (OTA) updates on Linux edge devices. It focuses on application and configuration releases: single Docker containers, Docker Compose applications, and configuration-only updates. The [release manifest specification](docs/Release-Manifest-Schema-v1.md) defines the release format and validation rules.
